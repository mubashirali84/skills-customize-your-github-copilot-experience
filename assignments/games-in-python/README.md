
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a word-guessing game in Python that uses strings, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Set Up the Game

#### Description
Create the game data and display the hidden word as the player makes guesses.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list.
- Accept letter guesses from the player.
- Show correctly guessed letters in their positions and keep unguessed letters hidden (for example, `_ _ _`).
- Track and display the number of incorrect guesses remaining.

### 🛠️ Complete a Round

#### Description
Run the guessing loop and finish the round when the player wins or runs out of attempts.

#### Requirements
Completed program should:

- Continue accepting guesses while the word is incomplete and attempts remain.
- End the round when the player guesses the word or has no attempts remaining.
- Display a win message when the player guesses the word.
- Display a lose message and reveal the word when the player runs out of attempts.
